# Gcode command handlers that can still take the printer down.
#
# Klipper turns any exception that is not a gcode error into "Internal error on
# command", which shuts klippy down and takes the MCUs with it. Everything here
# predates the check and lives in files this port has not otherwise touched, so
# it is recorded rather than rewritten.
#
# THIS LIST MAY SHRINK. It must never grow: a new handler gets a try or a
# `## GCODE_SAFE: <reason>` comment instead.
